# 高校数学「三角関数」インタラクティブ学習ポータル

高校数学Ⅱ「三角関数」の完全マスターを支援するWebインタラクティブ学習ポータルです。
トップページのポータルサイト（`index.html`）から、目的に合わせて3つの専門アプリケーションを選択・学習できます。

---

## 🏛️ ポータルサイト構成（主要16角 ＆ 実戦全44問収録）

```
hight-school/
├── index.html        # 🏠 インタラクティブ学習ポータル（アプリ選択トップページ）
├── cos_sin_tan.html  # 🎯 アプリ1: 三角関数主要角マスター (0°〜360°)
├── equations.html    # 📐 アプリ2: 三角方程式・三角不等式 徹底理解 (18問)
├── graph.html        # 📈 アプリ3: 三角関数グラフ描き方マスター (26問)
└── README.md         # 📖 ドキュメント（本ファイル）
```

すべてのページ上部には統一されたナビゲーションバー（`[🏠 ポータル]` `[📐 方程式・不等式]` `[📈 グラフ描き方]` `[🎯 主要角マスター]`）が備わっており、いつでも相互にワンクリックで切り替え可能です。

## 🎯 アプリ1: 三角関数主要角マスター (`cos_sin_tan.html`)

**「単位円と三平方・動径座標の直感連動で、三角比の値を瞬時に導く」**

### 🌟 主な機能
1. **4つの充実した学習・探求モード**:
   - **テストモード**: ランダムに出題される三角比の値を制限時間なしで瞬発力トレーニング（正解時は0.7秒後に自動で次問へ）。
   - **全角攻略モード**: 0°〜360°の主要16角を順番に網羅してチェック。
   - **円タップ練習モード**: 単位円上の点を直接タップすると、その角の $\cos, \sin, \tan$ の値と象限の解説を即座に表示。
   - **角度探求モード**: スライダーで $-1080^\circ \sim 1080^\circ$（+3回転〜-3回転）まで自由に角を回転させ、同界角や動径の傾きを視覚的に探求。
2. **動径成分の分解表示**:
   - $\cos \theta$ (赤: $x$ 座標)、$\sin \theta$ (緑: $y$ 座標)、$\tan \theta$ (黄: 接線上の傾き) を単位円上に色分け描画。
3. **度数法 (°) ⇄ 弧度法 (rad) のワンタッチ切替**:
   - $30^\circ, 45^\circ, 60^\circ$ 表記と $\frac{\pi}{6}, \frac{\pi}{4}, \frac{\pi}{3}$ 表記を自由に切り替えて学習可能。
4. **全画面表示対応 ＆ 効果音演出**:
   - 画面右上の全画面ボタンでフルスクリーン表示に切り替え可能。正解・不正解の効果音（ON/OFF可能）付き。

## 📐 アプリ2: 三角方程式・三角不等式 徹底理解 (`equations.html`)

**「単位円と波形グラフのダイナミック連動で、解の構造と角の探索を直感的に納得する」**

### 🌟 主な機能
1. **単位円と波形グラフ（θ軸 / t軸）の完全連動**:
   - スライダーまたは「自動進行」で角 $\theta$ を連続変化させると、単位円上の動径の回転と波形グラフ上のプロットがリアルタイムに同期。
2. **横軸切り替え機能**:
   - 「$\theta$ 軸」表示と、置換後の「$t$ 軸（$t = k\theta + \alpha$）」表示をワンクリックで切り替え。
3. **不等号向き自由変更**:
   - 三角不等式では、$>, \geqq, <, \leqq$ を自由に切り替え可能。条件を満たす領域の塗りつぶしや境界の破線・実線が動的に反転。
4. **全18問収録（教科書基本〜入試標準発展）**:
   - 基本例題（$\sin \theta = c$, $\cos \theta \leqq c$, $\tan \theta \geqq c$ など）
   - 置換・平行移動型（$\sin(\theta + \frac{\pi}{3}) = \frac{\sqrt{3}}{2}$, $\cos(\theta - \frac{\pi}{3}) \leqq -\frac{\sqrt{2}}{2}$ など）
   - 周期変化型（$\sin 3\theta = 1$, $\cos 2\theta \geqq \frac{1}{2}$, $\tan 2\theta = -\sqrt{3}$ など）
   - ポップアップモーダルから「すべて (18)」「三角方程式 (12)」「三角不等式 (6)」のカテゴリ別で素早く選択可能。

## 📈 アプリ3: 三角関数グラフ描き方マスター (`graph.html`)

**「波を先に描き、後からy軸を入れる最強の解法で、複雑な三角関数のグラフを完全攻略」**

### 🌟 主な機能
1. **「練習モード」と「テストモード」の2大モード搭載**:
   - **練習モード**: 全26問から好きな問題を選び、ステップバイステップでじっくり学習。
   - **テストモード**: 出題範囲（関数種別、係数有無、反転有無）を指定してランダムテスト。スコア・正答率・解答履歴を記録。
2. **主要5点プロットによる論理的作図法**:
   - 周期の判定 $\rightarrow$ 特徴点（交点・頂点・漸近線） $\rightarrow$ $y$ 切片 $\rightarrow$ 最大・最小値 $\rightarrow$ $y$ 軸の配置指定をガイド。
3. **「描画の極意」チートシート内蔵**:
   - いつでも基本公式や作図のコツをモーダルで確認可能。
4. **全26問収録（$\sin, \cos, \tan$ 網羅）**:
   - 基本形、平行移動、振幅変化、周期変化（$2x, 3x, \frac{1}{2}x, 5x$）、上下反転波形まで網羅。

## 🚀 起動方法

### ローカルで利用する場合
1. フォルダ内の `index.html` をブラウザ（Google Chrome、Microsoft Edge、Safari等）で開きます。
2. ポータル画面から使いたいアプリの起動ボタンをクリックしてください。

### GitHub Pages で公開する場合
1. 本リポジトリ（`hight-school`）を GitHub にプッシュします。
2. リポジトリの **Settings > Pages** で `main` ブランチの root を選択して保存します。
3. 数分後に公開URL（`https://<username>.github.io/hight-school/`）から、世界中どこからでも利用可能な学習サイトとしてアクセスできます。
