# 三角関数グラフ描き方マスター アプリ

画像の三角関数のグラフの描き方を実践的に学ぶ学習Webアプリケーションです。

## 🎯 アプリの学習コンセプト（裏ワザ定石）
いきなりx軸・y軸を描いてから波を描こうとすると、周期の幅や波の形が崩れてしまいます。
このアプリでは、大学受験や高校数学で推奨される**「波を先に描き、後からy軸を入れる最強の解法」**を体験・習得できます。

### 🌟 特徴・機能
1. **「練習モード」と「テストモード」の2大学習モード**:
   - ヘッダー上部のスイッチで **【🎯 練習モード】** と **【⏱️ テストモード】** をワンクリックでいつでも切り替え可能！
   - **【練習モード】**:
     - 全26問から好きな問題を自由に選んで、自分のペースでじっくりステップ学習＆再選択が可能。
   - **【テストモード】**:
     - **出題範囲を自由指定**: 関数の種類（tanなし、sin、cos、tan）、xの係数（なし/あり）、aの正負（正/負）を自由に組み合わせてテスト範囲を設定可能。
     - **範囲内から完全ランダム出題**: 実戦力・即答力を鍛えるランダム出題。
     - **リアルタイムスコア表示**: ヘッダーに正解数と正答率（例: `正解: 4 / 5 問 (80%)`）をリアルタイム表示。
     - **採点後のスムーズ進行**: 採点完了後、アクションボタンが「次のテスト問題へ ➔」になり、テンポ良く何問もトレーニング可能。
     - **「履歴を表示」ボタン＆成績サマリー**: これまでの解答結果（日時、問題式、正否、出題範囲）をローカルストレージに自動蓄積。通算正答率やストリーク（連続正解数）を確認可能。
2. **洗練された「問題選択ポップアップ」＆全26問を網羅**:
   - 練習モード時はヘッダーの**「問題を選択」ボタン**から、モーダルポップアップで直感的に問題を選択可能。
   - **「関数の種類」「xの係数」「aの正負」の3軸ANDフィルターパネル**を新設！
     - **条件1「関数の種類」**: 【すべて】 【**tan なし (sin・cos)**】 【sin のみ】 【cos のみ】 【tan のみ】
     - **条件2「x の係数」**: 【すべて】 【なし (係数1)】 【あり (周期変化)】
     - **条件3「a の正負」**: 【すべて】 【$a > 0$（正 / 標準）】 【$a < 0$（負 / 反転）】
     - ユーザーの好みの切り口（例:「tan なし」かつ「x の係数あり」など）ですべての条件を同時に満たす問題だけが瞬時に絞り込まれます。
     - 「指定条件を満たす問題: ◯件」と件数も即座に更新表示。
   - 各問題カードには `$a > 0$` や `$a < 0$ (反転)` のステータスバッジを表示。
   - 大問ごとの見出し（大問3, 4, 5, 8, 9, 10）で美しく整理。
   - **【xの係数なし (係数1) 全15問】**:
     - **大問3: 基本のグラフ**
       - 3-(1) $y = \sin x$
       - 3-(2) $y = \cos x$
       - 3-(3) $y = \tan x$
     - **大問4: 平行移動とグラフ**
       - 4-(1) $y = \sin(x - \frac{\pi}{4})$
       - 4-(2) $y = \cos(x + \frac{\pi}{6})$
       - 4-(3) $y = \tan(x - \frac{\pi}{3})$
       - 4-(4) $y = 2\cos(x + \frac{\pi}{4})$
       - 4-(5) $y = -\sin(x - \frac{4}{3}\pi)$
       - 4-(6) $y = 3\tan(x - \frac{\pi}{2})$ （$x=0$が漸近線、$y$切片なし）
     - **大問5: 応用・反転波形のグラフ**
       - 5-(1) $y = 2\cos(x - \frac{\pi}{3})$
       - 5-(2) $y = -\sin(x - \frac{\pi}{2})$
       - 5-(3) $y = 2\tan(x + \frac{\pi}{4})$
       - 5-(4) $y = -\frac{1}{2}\cos(x + \frac{2}{3}\pi)$ （反転$\cos$）
       - 5-(5) $y = 3\sin(x + \frac{5}{6}\pi)$
       - 5-(6) $y = -\tan(x - \frac{7}{6}\pi)$ （反転$\tan$）
   - **【xの係数あり (周期変化) 全11問】**:
     - **大問8: 周期変化の基本**
       - 8-(1) $y = \sin 2(x - \frac{\pi}{6})$ （周期 $\pi$）
       - 8-(2) $y = \tan\frac{1}{2}(x - \frac{\pi}{4})$ （周期 $2\pi$）
       - 8-(3) $y = -\cos 3(x - \frac{\pi}{3})$ （周期 $\frac{2\pi}{3}$）
       - 8-(4) $y = -\sin\{-2(x + \frac{\pi}{4})\}$ （周期 $\pi$）
     - **大問9: 様々な周期変化と対称性**
       - 9-(1) $y = 2\cos(\frac{1}{2}x - \frac{\pi}{6})$ （周期 $4\pi$）
       - 9-(2) $y = -\tan(3x + \frac{3}{4}\pi)$ （周期 $\frac{\pi}{3}$）
       - 9-(3) $y = \sin(\frac{2}{3}\pi - 2x)$ （周期 $\pi$）
       - 9-(4) $y = -\tan(\frac{\pi}{2} - 5x)$ （周期 $\frac{\pi}{5}$）
     - **大問10: 分数周期と複合変化**
       - 10-(1) $y = \frac{1}{2}\cos(2x + \frac{2}{3}\pi)$ （周期 $\pi$, 振幅 $1/2$）
       - 10-(2) $y = -\sin(\frac{2}{3}x - \frac{\pi}{6})$ （周期 $3\pi$）
       - 10-(3) $y = 2\tan(\frac{1}{2}x - \frac{\pi}{6})$ （周期 $2\pi$）
2. **y軸なしで3周期分の波形を先行描画**:
   - 初期状態ではy軸を描かずに、なめらかな波形とx軸のみを描画。
   - $\tan$ の場合もy軸を書かずに、3周期分のブランチと漸近線（薄い破線）を先行描画。
3. **STEP 1 で最初に関数の「周期」を4択から選択**:
   - グラフを描き始める前に、基本となる波1周分の長さ**「周期」**を4択から質問・選択。
   - 選択した周期は「決定した重要座標」のサマリーチップ（先頭）に登録され、クリックでいつでも選び直せます。
4. **メイン1周期の特徴点・y切片・代表値の4択選択**:
   - $\sin$ の場合：メイン1周期のx軸交点（交点A, 交点B, 交点C）のx座標を順番に選択。
   - $\cos$ の場合：メイン1周期の**頂点（スタートの山・中央の谷・終わりの山）**のx座標を順番に選択。
   - $\tan$ の場合：メイン1周期の**左漸近線・中央のx軸交点A・右漸近線**のx座標を順番に選択。
   - 続いて $x = 0$ を代入した **y切片** の座標を選択。
   - $\sin, \cos$ では **最大値** と **最小値** を選択。
   - $\tan$ では メイン1周期の範囲で **$\tan$ が $1$ になる $x$ 座標**（代表通過点 $(\pi, 1)$）を選択。
   - すべて4択を選ぶと自動でスムーズに次のステップへ進みます。
5. **決定した重要座標をクリックでいつでも再選択**:
   - 右側パネルの「決定した重要座標」の各チップ（周期、交点/頂点/漸近線、y切片、最大値/最小値/代表値、y軸位置）をクリックすると、いつでもそのステップへ瞬時に戻って選択肢を選び直すことができます。
   - プログレスバーの各ステップ番号ノブも同様にクリックでジャンプ可能。
   - 採点後でもチップをクリックすれば採点結果がリセットされ、間違えた箇所だけをすぐに選び直すことができます。
6. **マウス操作によるy軸（$x=0$）の配置指定**:
   - 座標選択完了後、グラフ上でマウスを動かすとy軸がドラッグ追従表示（余計な文字説明は表示されません）。
   - **クリックで配置固定**: クリックするとy軸がその位置にピタッと固定され、マウスを動かしても動きません。
   - **再ドラッグ**: 位置を変更したいときは、グラフ上をもう一度クリックすると再度ドラッグ状態に戻ります。
   - **周期の四分の1の区間で正否判定**: $x=0$ が通る区間を、周期の四分の1の単位で厳密かつ分かりやすく判定します。
7. **採点＆完成グラフ描画**:
   - 採点前はメイン1周期に本当の周期（$2\pi$ や $\pi$）の数値を書かず、採点後に本当の周期を表示します。
   - 「採点する」ボタンで判定。
   - **正解の場合**: 原点O、y軸、各交点、極値/漸近線、代表点、y切片の数値と補助点線が入った「正しい完成グラフ」を美麗に描画！
   - **不正解の場合**: 誤りのある箇所をフィードバックし、「やり直し」ボタンでリトライ可能。
8. **「描き方の極意」モーダル＆KaTeX美麗数式表示**:
   - ヘッダー右側の「描き方の極意」ボタンから、いつでも三角関数グラフ描画の王道定石（①周期 → ②y軸抜き波形 → ③メイン1周期の特徴点 → ④y切片 → ⑤最大/最小/代表点 → ⑥y軸の配置）をステップごとに確認可能。
   - すべての数式（y, x, T = 2π/|k|, a < 0 など）が KaTeX で美しくレンダリングされ、閉じるボタン（×）や背景クリック・Escキーで素早く閉じられます。
9. **PC画面・スクロールなし・ダークモード・全画面表示**:
   - スクロール不要のジャストフィットUI。
   - 目に優しいスタイリッシュなダークテーマ。
   - 右上の「全画面」ボタンで大画面で集中して学習可能。

## 🚀 起動方法
ブラウザで直接 `index.html` をダブルクリックして開くか、またはローカルサーバーで実行してください。
